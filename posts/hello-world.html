为什么我又开始写博客了

约 3 分钟·Lulu Lennon

输出是最好的输入。很多时候我以为自己懂了，直到试图把它讲清楚——卡壳的地方，就是理解真正的缺口。

为什么记录有价值

  • 对抗遗忘：三个月前调通的方案，细节早就模糊了，但写下来的东西翻回来五分钟就能捡起。
  • 检验理解：写不出来 = 没懂透。写作是最便宜的自我测试。
  • 复利效应：一篇篇小的技术笔记，几年后就是自己的知识库。

这个站是怎么搭的

没有用任何框架，纯 HTML + CSS + 一点点 JS，直接部署在 GitHub Pages 上。零依赖、零构建，想改哪里就改哪里。

比如下面这段：

// 行内代码和代码块都长这样
const blog = { deps: 0, build: false, speed: "∞" };
如果一条 insight 不值得花十分钟写下来，多半也不值得记住。
